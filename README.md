# 空也科技公司官网

北京空也科技有限公司（Beijing Kongye Technology Co., Ltd）的公司与产品展示网站。

- 正式域名：https://kongye.space/
- 产品：窗后城（开发中的 iOS 应用）
- 网站目录：`docs/`
- 托管：GitHub Pages，发布分支 `main`，目录 `/docs`

## 更新网站

修改 `docs/` 内的 HTML、CSS、JavaScript 或图片，提交并推送到 `main` 后，由 GitHub Pages 更新网站。无需安装依赖或构建。

`privacy.html`、`terms.html`、`community-rules.html` 当前明确标为开发版本草稿，尚未正式生效。

第三方三维示例素材的来源和许可见 [ATTRIBUTION.md](ATTRIBUTION.md)。
