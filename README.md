# 空也科技公司官网

北京空也科技有限公司（Beijing Kongye Technology Co., Ltd）的公司与产品展示网站源码。

- 正式域名：https://kongye.space/
- 产品：窗后城（开发中的 iOS 应用）
- 新版静态文件：`docs/`

## 发布状态

正式域名继续使用原托管平台。该仓库保存新版页面；GitHub Pages 仅用于预览，当前未绑定正式域名。推送本仓库不会自动更新原托管平台上的正式官网。

待原托管平台的项目发布访问恢复后，可将 `docs/` 的内容部署回原项目。网站无需安装依赖或构建。

## 更新预览

修改 `docs/` 内的 HTML、CSS、JavaScript 或图片，提交并推送到 `main`，由 GitHub Pages 更新预览。发布分支为 `main`，目录为 `/docs`。

`privacy.html`、`terms.html`、`community-rules.html` 当前明确标为开发版本草稿，尚未正式生效。

第三方三维示例素材的来源和许可见 [ATTRIBUTION.md](ATTRIBUTION.md)。
