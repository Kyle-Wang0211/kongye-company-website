# Resort point-cloud guide

Screen two opens a resort guide template. The homepage keeps three screen covers and solid selection dots, with no black focus ring.

The guide reuses the existing bundled OpenLiDARViewer, native COPC streaming, camera poses and annotations. The complete AHN6 2025 Giethoorn one-square-kilometre tile is preserved byte-for-byte in cloud storage. Ten local XYZ labels on actual classified building records open facility descriptions and saved close-up views. Category controls filter native markers and the list. Return-to-overview restores the configured camera.

Cloud data remains a separately managed immutable resource. Its SHA256 is 5f901db59fa81190e8273129c1fb81f95d97b5971e32a88b4ffa1d4db950c90b. AHN attribution and CC BY 4.0 links are visible. Yunqi resort, cooperation branding, facilities and room numbers are explicitly identified as fictional template content.

Acceptance uses existing scoped Node checks and a bounded real-browser pass for a rendered multi-building cloud, native marker popup, camera reset, homepage return and removal of the selector ring. Existing ceramic and third-screen pages retain their behavior.
