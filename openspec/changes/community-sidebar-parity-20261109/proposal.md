# One community sidebar specification
Primary entries are Hot, Following, My profile and Messages, in that order. Sidebar branding, width, breakpoints, icon geometry, typography, spacing, selected appearance and settings/legal footer match community-shell.css. Profile pages retain the same desktop sidebar and compact rail, with stable child state across resizing. Publishing remains in existing header/account menus, not a fifth primary sidebar module. Settings and Following reuse the homepage's existing panels/session flow; no replacement backend.

Profile editing uses boxed nickname and multi-line bio fields with visible grapheme counts and existing backend maxima (20/160), preserving draft, moderation and account ownership behavior. No production account test writes or mobile deployment.
