# Browser GLB publication

Signed-in community users open the upper-right plus, choose a GLB (maximum 50,000,000 bytes), reuse the existing product selection viewer or retain the entire GLB, and enter a Unicode title (1–100 code points) and description (0–30). The browser submits immutable original bytes and optional selection metadata to the existing publication-submit initiate / signed private upload / seal / status contract. No renderer, processing algorithm, signing protocol, or new dependency is introduced.

The publication idempotency key, source hash, selection, title, description, and submission ID are saved by account before relevant network operations. Lost responses reuse that key; restoring an uploading draft requires the identical GLB. Status is server-authoritative, and pending/rejected/private drafts never enter the public feed. Switching accounts invalidates the page and service owner; polling and response display stop.

The viewer's own public, moderation-ok, non-deleted, published works are queried separately, merged and sorted first only for that viewer. The ordinary public cursor remains separate from the display order. Account changes clear and reload the feed.

Selection support is ported narrowly from the existing phone product source (specified revision a82410e); unchanged Three.js engine files, the web viewer's canonical framing and existing pointcloud comments remain intact. Browser SelectionBox excludes only filesystem archive methods. The reusable page binds directly to the same SharedViewer controller with immutable picked bytes instead of a phone filesystem URL. Camera controls are extracted from the existing controller, with no point-cloud renderer import.

Acceptance: focused service and own-feed tests; selection math and runtime bridge tests; no-pub web release build; actual authenticated browser/backend receipts before any E2E claim. No push, deployment, or device writes are authorized by this change.

Review corrections: authenticated cancellation uses the existing server cancel action. Only a known terminal status enables a new draft; an ambiguous cancellation preserves the original account-scoped submission and offers status recovery. Cancellation does not require the source GLB. Account invalidation clears all private controllers and transient fields, removes the specifically owned nested selection and publication routes (including a non-poppable selection), and renders no private controls for a stale identity. Recovery widget tests cover cancellation, a lost cancel response, logout during nested selection, and a replacement account after restoring private state.

The browser artifact must be built with the existing website's public China deployment config (origin pinned to api.kongye.space, public JWT role anon). A build without those definitions proves compilation only and is not a usable China browser artifact. The final reviewed candidate uses a task-local define file; no credential is added to source.

Browser packaging correction: the selection runtime module is explicitly declared in the shared viewer package asset list. Source manifest checks alone do not prove that Flutter copied all resources into the browser artifact. A built-output regression check now requires every declared bundle-manifest file to exist under the generated browser viewer directory and match its frozen SHA-256. The pre-fix artifact fails specifically for the missing publication_selection.mjs; deferred iframe-attachment/layout hypotheses are excluded from the candidate.

Browser tooling diagnosis: root observed a paused Browser Use document response. Resetting only the automation session immediately rendered the same already-open Avocado and selection box; keep-all/restore also updated the real preview. The speculative attachment host/helper/test were removed from the shipping candidate, and the web host was restored byte for byte to its reviewed baseline. The candidate retains only the existing selection feature bridge and required asset packaging. A final rebuild and root browser retest bind that unchanged host to the shipped artifact.
